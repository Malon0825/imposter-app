# UI proposal generation prompts

Built-in image_gen tool. Images 2–6 use image 1 as a style reference only.

## Shared design specification

High-fidelity Android-first mobile app UI proposal for a face-to-face social deduction game named IMPOSTER. Create a polished landscape 3840x2160 screen-flow presentation, FOUR large identical thin graphite Android phone mockups in ONE horizontal row, full devices evenly spaced on warm ivory studio background, screen content dominates. Thin centered hole-punch camera, Android status bar, bottom gesture area. Consistent design bible: matte charcoal #171A18 main app surfaces, warm ivory #F4F1E8 primary text, muted sage secondary text, vivid yellow-lime #D6F56B primary actions, terracotta #D98672 only negative-result emphasis. Refined rounded grotesk type, comfortably large readable UI text, strong hierarchy, generous spacing, 16px card radii, 52px buttons. Minimal flat structure, not nested cards, no gradients, no neon glow, no dashboards, no bottom tabs during a round. Custom restrained eye/secret-card motif and friendly two-letter player avatars. Small presentation title top-left, clearly numbered phone captions below and arrows with short motion notes BETWEEN phones, all outside the actual app UI. Realistically buildable premium game app, not a website. No timer anywhere. Each phone is a DISTINCT functional page; keep important copy accurately spelled and large. Use ample image resolution.
