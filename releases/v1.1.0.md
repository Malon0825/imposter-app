# Imposter 1.1.0 — offline browser guest preview

Only the host needs the Android app. Friends can join the same party in an iPhone or Android browser, offline on shared Wi-Fi.

[See actual app screenshots and the website setup](https://github.com/Malon0825/imposter-app/blob/main/docs/README.md#screenshots).

## Install and join

1. Download **imposter-1.1.0-android.apk** below and install/update Imposter on the Android host. This uses the same release signing key as 1.0.0.
2. Connect all phones to the same reachable Wi-Fi router.
3. Create a party and show its invitation QR. Connect to the Wi-Fi **before** scanning.
4. Scan with the phone's Camera/QR reader to open browser joining. Your selected browser is supported by design; Safari is not required.
5. If you have the updated Android app, use **Join party → Scan invitation** to play natively. Android browser joining also offers a user-tapped **Open in Imposter** option where the browser supports it.

Requires an ARM64 Android 8+ host; x86_64 is also included for emulators. No Apple account, TestFlight, app installation for browser guests, public website, or internet connection is required for gameplay. Older Android app versions need an update to recognize the new shared URL QR.

## Included

- One shared QR for installed Android apps and browser guests, using one authoritative Rust game.
- Browser identity recovery, duplicate-tab protection, safe join/action retries, private role concealment, and the complete existing game flow.
- The approved UI and motion, including reduced motion and compact-screen layouts.
- An APK-bundled guest website and barcode model for offline use.
- Native certificate-pinned HTTPS retained for installed guests.

Browser guests use **unencrypted local HTTP**. Use Wi-Fi you trust: someone able to inspect/alter network traffic could compromise roles, credentials, or votes. Browser HTTP warnings and router isolation settings can affect joining.

## Preview validation

Tested with all 15 Rust transport/game tests, Chromium/WebKit/Firefox automation, 12-player browser capacity, existing native-client and motion regression scenarios, and an installed Android emulator hosting a mixed native/browser game. The signed release APK also passed cold/warm app-opening invitations, native guest voting/final rankings, bundled scanner startup, and cancellation. The APK is signed and aligned; its download checksum is attached.

**Physical iPhone browsers, real camera QR recognition, and real shared-router traffic remain unverified because test devices are currently unavailable.** This release is a preview for that device validation, rather than a fully hardware-validated browser release.

Keep the host available throughout the party and leave its final recap open until friends see the rankings. Force stopping the host ends the party. Refreshing a guest after the host closes cannot recover an ended session.
