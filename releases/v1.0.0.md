# Imposter 1.0.0

The first Android release of Imposter: a local multiplayer party game where each player uses their own phone.

## Download and install

1. Download **imposter-1.0.0-android.apk** from the assets below on your phone.
2. Open the download. If prompted, allow your browser to install this app, then select **Install**.
3. Open **Imposter** and connect every player's phone to the same Wi-Fi router.
4. One player chooses **Host party**; everyone else chooses **Join party** and scans the host's QR code.

Requires Android 8 or newer and an ARM64 phone. The APK also includes x86_64 for emulators. No account or internet service is required for native play. If you installed an earlier development/debug APK, uninstall it before installing this signed release; subsequent signed releases can update it normally.

## Included

- Parties for 3–12 players, with QR invitations and encrypted local connections.
- One random imposter, private word/hint cards, and secret voting.
- Runoff ties, individual scoring, sequential Drink/Dare/Skip turns, and cumulative rankings.
- 22 offline topic packs with 221 authored word/hint pairs, including opt-in sex education and relationships.
- The approved dark interface, spring interactions, draggable sheets, animated cards and scores, and a brief celebration. Reduced motion is supported.
- Android background-hosting setup and reconnect handling.

The host phone must remain available. Force stopping it ends the party. iOS is planned for a later release.

## Validation

Production frontend build, 12 Rust tests, the four-player/two-round game scenario, 24 compact layouts, motion/reduced-motion checks, and Android emulator checks. The APK signature and 16 KB ZIP alignment are verified during packaging. The attached `.sha256` file can verify the download.
