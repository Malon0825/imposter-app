# IMPOSTER

Android-first local social deduction game, built with Tauri 2, Rust and React. iOS is a later target. Product rules and authority boundaries live in PLAN.md; word catalog lives in TOPICS.md. No accounts, cloud party service, discussion timers, AI dares, or role rotation. One random imposter each round always gets an indirect starting hint. Everyone votes privately; correct civilians earn +1 and escaping imposters +2. One runoff, then imposter escape on a repeated tie. Human-given dares, sequential punishment turns, cumulative rankings. See PLAN.md for complete mechanics.

The user approved design/proposal-v1/*.png and requested faithful implementation with animations. This is implementation authorization, not an open visual exploration. Do not replace the approved design with generated alternatives.
